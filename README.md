📚 Interactive Matdas

«Belajar Matematika Dasar bukan cuma dengan membaca, tapi dengan memahami, mencoba, dan berinteraksi.»

Interactive Matdas adalah media pembelajaran interaktif berbasis web yang dibuat untuk membantu mahasiswa memahami materi Matematika Dasar (Matdas) dengan pendekatan visual, interaktif, dan latihan langsung.

Project ini dikembangkan dari materi PPT perkuliahan dan dirancang untuk mengubah materi pembelajaran yang biasanya bersifat pasif menjadi pengalaman belajar yang lebih aktif.

---

✨ Features

- 📖 Slide-by-Slide Learning
  Membahas seluruh materi dari PPT secara berurutan tanpa melewatkan slide.

- 🧠 Interactive Learning
  Konsep dibuat lebih mudah dipahami melalui visualisasi, input, kalkulator, tabel interaktif, dan elemen interaktif lainnya sesuai kebutuhan materi.

- 🧮 Interactive Calculator
  Mencoba perhitungan secara langsung dan melihat perubahan hasil secara real-time.

- 🃏 Flashcards
  Mengulang definisi, rumus, konsep penting, dan istilah melalui flashcard interaktif.

- ✍️ Practice Questions
  Latihan soal dengan feedback dan pembahasan langkah demi langkah.

- 🤔 "Gue Gak Paham" Mode
  Penjelasan ulang konsep menggunakan bahasa yang lebih sederhana.

- 📕 Mistake Review
  Menyimpan soal yang pernah dijawab salah sehingga dapat dipelajari kembali.

- 📊 Progress Tracking
  Memantau progress pembelajaran berdasarkan topik dan slide.

- 📝 Quiz Mode
  Menguji pemahaman setelah menyelesaikan materi.

- 📌 Cheat Sheet
  Ringkasan rumus, konsep, tabel, dan poin penting untuk review cepat.

- 🌙 Dark Mode UI
  Tampilan modern dan nyaman digunakan untuk belajar.

- 📱 Responsive Design
  Dapat digunakan melalui smartphone, tablet, maupun laptop.

🎯 Learning Flow

Interactive Matdas menggunakan alur pembelajaran:

📖 Learn
   ↓
🧠 Understand
   ↓
🎮 Interact
   ↓
✍️ Practice
   ↓
💡 Get Feedback
   ↓
🔁 Review
   ↓
📝 Quiz

Tujuannya bukan sekadar mendapatkan jawaban yang benar, tetapi memahami mengapa jawaban tersebut benar.

📚 Content Coverage

Materi pembelajaran berasal dari PPT Matematika Dasar yang digunakan sebagai sumber utama.

Setiap slide diproses dan dibahas di dalam aplikasi.

Cakupan dapat meliputi:

- Konsep
- Definisi
- Rumus
- Contoh soal
- Perhitungan
- Tabel
- Diagram
- Latihan
- Catatan penting
- Kesimpulan

«Tidak ada slide yang sengaja dilewati hanya karena dianggap sederhana atau kurang penting.»

Materi tambahan hanya digunakan jika diperlukan untuk membantu menjelaskan konsep dari PPT.

🚀 Getting Started

Clone repository:

git clone https://github.com/USERNAME/interactive-matdas.git

Masuk ke folder project:

cd interactive-matdas

Kemudian buka:

index.html

di browser.

Tidak membutuhkan instalasi dependency atau server khusus.

🎨 Design Philosophy

Interactive Matdas dibuat dengan prinsip:

«Less passive reading, more active learning.»

Antarmuka dibuat sederhana dan fokus pada materi.

Animasi dan elemen visual digunakan untuk membantu pemahaman, bukan sekadar mempercantik tampilan.
